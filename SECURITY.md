# Security Policy

## Supported Versions

Only the current active release line of CHANDANALA CORE™ ERP receives security updates and vulnerability patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security and integrity of CHANDANALA CORE™ ERP seriously. If you discover a security vulnerability, please follow these reporting guidelines:

### How to Report
* **Do NOT open a public GitHub issue** for suspected security vulnerabilities.
* Report vulnerabilities directly via email to: **security@chandanala.com** *(or submit via GitHub Private Vulnerability Reporting in repository settings)*.
* Please include details such as:
  * Type of issue (e.g., authentication bypass, SQL injection, privilege escalation).
  * Clear step-by-step instructions or proof-of-concept (PoC) to reproduce the flaw.
  * Affected capability module or API endpoint.

### What to Expect
* **Initial Response:** Within **48 hours** acknowledging receipt of your report.
* **Status Updates:** Every **3 to 5 business days** regarding triage, impact assessment, and patch progress.
* **Fix & Release:** Critical vulnerabilities are addressed via emergency hotfix releases. Once a fix is verified, a patch will be deployed and advisory disclosure will be coordinated.
