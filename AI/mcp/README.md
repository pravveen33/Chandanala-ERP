 # CHANDANALA CORE™ MCP Foundation

## Purpose

Provide secure, governed AI access to enterprise capabilities.

## Design Principles

- Provider Neutral
- Zero Cost
- Read Only by Default
- Capability Gateway First
- No Direct Database Writes
- Full Audit Logging
- Human Approval for Business Changes

## MCP Servers

- GitHub
- Filesystem
- PostgreSQL
- OpenAPI

## Security

- Least Privilege
- OAuth Authentication
- Read-Only Access
- HTTPS Required
- Audit Every Request
