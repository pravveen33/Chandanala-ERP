# CHANDANALA CORE™ Engineering Charter
**Version:** 1.0 | **Status:** Frozen

1. **Business Autonomy:** The platform serves business intent. Software is an implementation of intent, never a replacement.
2. **Deterministic Integrity:** Clinical, legal, and financial logic must be 100% deterministic. Probabilistic outputs (AI) are prohibited from the core.
3. **Loose Coupling:** Modules interact through explicit, immutable message contracts.
4. **Governance as Infrastructure:** Identity, Policy, Audit, and Observability are non-negotiable infrastructure.
5. **Intelligence as a Service:** AI capabilities are decoupled, swappable service modules.
6. **Universal Experience:** A singular business backend serves all client experiences.
7. **Quality through Governance:** The path to production is gated by automated, objective metrics.
