# GLOSSARY.md
| Term | Definition |
| :--- | :--- |
| **Capability** | A business function (e.g., Sales, Inventory). |
| **Module** | A deployable unit implementing one or more capabilities. |
| **Domain Event** | A record of a business fact emitted by the Deterministic Core. |
| **Governance Fabric** | Infrastructure for security, audit, and policy enforcement. |
